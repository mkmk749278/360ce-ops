Layer 1 — Context: was this sweep taken in balance or in imbalance?

§1 of the program doc defines price action as a four-layer read. This lane shipped with layer 2 (LevelBook), layer 3 (sweep + reclaim) and layer 4 (footprint delta) — and no layer 1 at all, while volume_profile.py had computed POC and the value area since long before the lane existed and the lane never imported it.

Why this split and not another: a sweep + reclaim is a failed break, so it is a mean-reversion trade. It pays in balance — price rotating inside a value area, rejected at the edge, returning toward POC — and it is a trap in imbalance, where value is being accepted away from the area and each failed break is a pause before continuation. Those two states produce an identical layer-2/3/4 signature: same level, same sweep, same aligned delta. That is why nothing already stamped could separate them, and why every other column on this page reads like noise.

These stamps arrive from 2026-08-07, so earlier rows are unstamped — counted apart, never folded into a real bucket, and not backfillable: the value area at entry is knowable only at entry. Expect this table to be mostly unstamped until new rows arrive.
