Layer 1 — was the prevailing trend with the trade?

§1 of the price-action program defines this lane's own trigger relative to the prevailing trend: a break with it is a BOS (continuation), against it a CHoCH (reversal). The lane takes both identically — it reads location, trigger and confirmation, and has no context layer at all. This is the first split that can say whether that is what costs it.

The field was declared and never assigned until 2026-08-06, so every earlier row is unstamped — counted apart, never folded into a real bucket, and not backfillable: the regime at entry is knowable only at entry. This table is expected to be almost all unstamped today, and to become readable as new rows arrive. That is the honest state, not a fault.
