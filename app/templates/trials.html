Activating is deliberately not a button here. Turning on {{ funnel.days }} free days of {{ funnel.tier }} for the whole eligible base is an owner-sign-off decision that should cost a deploy, not a click: set SIGNUP_TRIAL_ENABLED=true in the engine .env and run deploy.sh. Full runbook, including rollback semantics, is docs/SIGNUP_TRIAL_ACTIVATION.md in 360-v2.

Rollback stops new claims immediately but does not confiscate a running trial — banked grants keep resolving until they expire, exactly like referral rewards. Revoking automation from under a user mid-window is worse than letting at most {{ funnel.days }} days run out.
